# Food CRM Complete Frontend Template

Complete frontend starter for the Food CRM.

## Pages
- `dashboard.html` — main CRM dashboard
- `settings.html` — complete user/system settings

## Assets
- `assets/css/style.css` — latest uploaded dashboard stylesheet
- `assets/css/settings.css` — settings-specific styling
- `assets/js/app.js` — dashboard interactions
- `assets/js/settings.js` — settings persistence and controls

## Settings functionality
- Light / Dark / System theme
- Small / Medium / Large font size
- Navy / Blue / Teal / Indigo accent
- Compact / Comfortable density
- Notification preferences
- Regional defaults
- Dashboard preferences
- Session timeout
- 2FA and login alert toggles
- Save confirmation
- Reset to defaults
- LocalStorage persistence

## Technology
- Bootstrap 5.3
- Bootstrap Icons
- Poppins
- HTML5 / CSS3 / JavaScript
- Designed for direct integration into Django templates
